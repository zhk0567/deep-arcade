# 大肥鱼跳一跳 · 好友试玩版 v11

Cocos Creator Web 构建的完整跳一跳试玩版。

- 入口：`index.html`（带返回游乐场顶部栏）
- 游戏画面：`play.html`
- 资源：`assets/`、`cocos-js/`、`src/`
- 引擎许可：`licenses/COCOS-ENGINE-LICENSE.md`
- 版本：`version.json`
- 部署方式：纯静态，直接由 Nginx / GitHub Pages 提供
- 不需要包内的 `runtime/node.exe`、`server.mjs` 或启动 CMD

主站「跳一跳」卡片会当前页跳转到 `jump/`。
