# 合成大肥鱼 · 生产版

这是当前站点实际打开的 `v0.6.8` 完整版：

- 首屏：`index.html`（约 219 KB）
- 外部素材：`assets/`（23 张 WebP 立绘 + 21 条 MP3 语音）
- 入口：<https://大肥鱼.fun/fat-fish/>
- 主站卡片与旧版 `/fish-v068*.html` 均会跳转到这里

本目录只放**运行时文件**。完整源码、原始 PNG 素材、Node 排行榜后台、测试与微信小游戏骨架曾归档在仓库的 `source/merge-fat-fish/`；该目录已从发布树移除，需要时从 git 历史恢复。

注意：

- 不要只复制 `index.html`，必须连同 `assets/` 一起部署
- 页面内素材使用相对路径 `assets/`
- 返回主站使用 `../`
- 修改页面后建议使用新目录或新文件名，GitHub Pages 有约 10 分钟缓存
