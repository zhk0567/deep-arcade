# 合成大肥鱼 v0.6.8

10 级角色的物理合成游戏，包含人物图鉴、首次解锁卡片、互动语音、存档续玩和 Node.js 排行榜后台。

本目录独立于仓库根目录现有的深海游乐场；根目录网站中的简化合成游戏仍保留。

## 运行完整版

需要 Node.js 18 或更新版本，无需安装 npm 依赖。

```bash
cd merge-fat-fish/web
node server.cjs --port 4173
```

浏览器访问 http://127.0.0.1:4173/ 。Windows 也可双击 `web/开始游戏.cmd`。

手机与电脑在同一局域网时，可使用 `node server.cjs --host 0.0.0.0 --port 4173`，再用电脑的局域网 IP 访问；防火墙需允许对应端口。

排行榜由同一个 Node 服务提供，每个玩家仅保留最高分，服务端重放核分。运行数据写入 `web/runtime-data/`，已排除提交。公网部署需另行配置 HTTPS、域名与持久化存储，见 [后台部署说明](web/后台部署说明.md)。GitHub Pages 仅提供静态文件，不能运行此排行榜后台。

## 目录

- `web/`：当前完整浏览器版本、素材、后台与测试。
- `wechat-minigame/`：v0.6.5 微信小游戏移植骨架；具有投放、合成、计分与暂停功能，尚未同步完整版首页、图鉴、语音、续玩与最新失败判定。

微信骨架在开发者工具中作为“小游戏”导入；当前 AppID 为测试占位符，正式上传需换为自己的 AppID。此仓库不是可以直接提交审核的完整微信或抖音小游戏包。

## 当前规则

- 1—4 级投放概率为 50%、30%、15%、5%。
- 10 级路径：蓝鲸团子 → 泡泡鲸宝 → 见习鲸侍 → 灵尾鲸侍 → 王庭侍长 → 海月鲸姬 → 夜宴贵姬 → 凤仪王女 → 星海鲸神 → 沧海女帝。
- 已接触球堆的球碰到警戒线时提醒；越过线的高度超过自身直径三分之一时立即失败，没有倒计时。
- 首次实际合成五级及以上新角色时在对局内展示解锁卡，手动收下；发现记录跨对局保存。
- 互动与鼓励语音采用选定的 G 音色。前端版本 0.6.8，物理与核分规则仍为 0.6.6。
